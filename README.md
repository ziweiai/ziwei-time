# ziwei-time

**把「出生地钟面上写的那一刻」换算成「当地真太阳时」，并给出对应的时辰 —— 含 IANA 时区、夏令时规则、均时差与晚子时裁决。**

零依赖、纯 JS、Node 18+。不做排盘，不论命，不含任何吉凶规则。

```bash
npm install ziwei-time
```

```js
import { trueSolarTime } from 'ziwei-time';

trueSolarTime({ date: '2002-07-07', time: '05:05', city: '洛杉矶' });
// → trueSolar: '2002-07-07 04:08'，branch: '寅'，correctionMinutes: -57
```

同一个函数，不传 `city` 只传经度也能用：

```js
trueSolarTime({ date: '1972-11-08', time: '00:36', longitude: 104.07 });
// → trueSolar: '1972-11-07 23:48'（date 退一天），lateZi: true，timeIndex: 12
```

## 为什么需要它

排盘引擎（比如 iztro）通常只接受「某年某月某日 + 第几个时辰」。但从出生证上的钟表时间到那个时辰，中间有四道坑，每一步都能让整张盘错一档：

| 坑 | 后果 | 本库怎么处理 |
|---|---|---|
| **夏令时** | 北美/欧洲/南半球夏季民用时比标准时快 1 小时 | 海外城市走 IANA tz database，历史规则也在内 |
| **西经爆表** | 按 `(经度−120)×4` 算修正，洛杉矶会得到 −953 分钟，跨到前一天且时辰全错 | 按当地民用时先折算 UTC，再加经度差 |
| **跨日截断** | 乌鲁木齐 01:30 的真太阳时是前一日 23:xx，被 `clamp(0,1440)` 截成当日 00:00 → 日柱错一天 | 明确进退日期，返回 `dayShift` |
| **中国 1986–1991 夏令时** | 这六年出生的人，钟面时间比标准时快 1 小时 | 内置 tzdata 区间表，区间内自动回退 60 分钟 |

实测锚点：**2002-07-07 05:05 洛杉矶**。不含夏令时的口径算出卯时、命宫卯；含夏令时算出寅时、命宫巳 —— 差两宫，不是「差几分钟」。

## API

### `trueSolarTime(options)`

| 参数 | 类型 | 说明 |
|---|---|---|
| `date` | string | 出生地钟面日期 `YYYY-MM-DD`（必填） |
| `time` | string | 出生地钟面时间 `HH:mm`（必填） |
| `city` | string | 城市名（中文即可），自动带出时区与经度 |
| `timezone` | string | IANA 时区，优先于 `city`，如 `America/Los_Angeles` |
| `longitude` | number | 经度，东经为正、西经为负；城市未收录时用 |
| `equationOfTime` | boolean | 是否计入均时差，默认 `true`；关掉可复现「只按经度」的旧口径 |

返回：

```js
{
  civil:        { date, time, minutes },      // 输入的民用时
  trueSolar:    { date, time, hour, minute }, // 换算后的真太阳时（可能换日）
  correctionMinutes,                          // 总修正（分钟）
  longitudeMinutes, eotMinutes, dstMinutes,   // 各项修正的分解
  timezone, longitude, path,                  // path: 'iana' | 'meridian'
  branch, branchIndex, timeIndex, lateZi,     // 时辰：0–11 子…亥，12 = 晚子时
  dayShift                                    // -1 退日 / 0 / +1 进日
}
```

### 其它导出

| 函数 | 用途 |
|---|---|
| `hourBranch(hour, minute)` | 钟面时刻 → 时辰（不换算真太阳时） |
| `resolveTimezone(city)` | 城市名 → IANA 时区，未收录返回 `null` |
| `cityCoords(city)` | 城市名 → `[经度, 纬度]` |
| `tzOffsetMinutes(utcMs, tz)` | 某瞬间某时区的民用时偏移（分钟） |
| `chinaDstMinutes(y, m, d, h, min)` | 是否处于中国 1986–1991 夏令时 |
| `equationOfTime(y, m, d, hour=12)` | 均时差（分钟），Meeus 高精度算法，误差 < 1 秒 |
| `equationOfTimeApprox(y, m, d)` | 旧近似式，**仅供对照**（实测最大偏差 65 秒） |
| `julianDay(y, m, d, hour)` | 儒略日 |
| `BRANCHES` | 十二地支 |

### CLI

```bash
npx ziwei-time --date 2002-07-07 --time 05:05 --city 洛杉矶
# 民用时    2002-07-07 05:05  America/Los_Angeles
# 真太阳时  2002-07-07 04:07
# 时刻      寅时   timeIndex=2
# 修正      -58 分钟  [经度 -53.0 / 均时差 -4.9]

npx ziwei-time --date 1972-11-08 --time 00:36 --city 成都 --json
```

## 口径说明

**三条换算路径，按优先级：**

1. **IANA 时区**（海外 + 港澳台）—— 民用时 → UTC → `UTC + 经度×4min + 均时差`。夏令时由 tz database 处理，包括 1985 年美国 4 月末切换这类历史规则。
2. **中国内地** —— 民用时恒为北京时间（120°E），只算「经度差 + 均时差」；1986–1991 年间先回退 60 分钟。
3. **只有经纬度、没有时区** —— 按最近的 15° 整数倍中央经线估算，误差 ≤ 1 小时。拉美、非洲等无 tz 数据的地区会走这条，需要精确请传 `timezone`。

**均时差**用一阶近似式（`9.87 sin2B − 7.53 cosB − 1.5 sinB`），全年误差约 ±20 秒 —— 相对 2 小时的时辰刻度可以忽略，但**不要拿它做天文用途**。

**晚子时**：23:00–23:59 属当日晚子时，返回 `timeIndex: 12`，不自动折算成次日早子时。要不要「归次日整盘」是排盘层的口径，本库只标注，不替你决定。

**误差来源**（本库不解决，需要更大精度请换星历表）：均时差近似 ±20 秒；城市坐标取两位小数（≈±1 km，<5 秒）；真太阳时不含大气折射与海拔。

## 与排盘引擎的关系

```
出生地钟面时间
      ↓  ← 本库负责这一段（时区 / 夏令时 / 均时差 / 跨日 / 时辰）
   真太阳时 + 时辰索引
      ↓  ← 交给排盘引擎（如 iztro 的 astro.bySolar(date, timeIndex, gender)）
     命盘
```

本库不替代任何排盘库，只补它普遍缺的那一层。两者组合即可。

## 收录范围

- **中国内地 42 城**（北京/上海/广州/深圳/成都/重庆/杭州/武汉/西安/乌鲁木齐/拉萨/哈尔滨…）
- **中国香港 / 中国澳门 / 中国台湾**（台北/高雄/台中）
- **海外 60+ 城**（东京/首尔/新加坡/伦敦/巴黎/纽约/洛杉矶/温哥华/悉尼/奥克兰/圣保罗…）

城市名支持后缀（`上海市`、`日本东京`）。未收录城市直接传 `longitude`，或传 `timezone`。

⚠️ **重名城市必须带大洲**：`北美洲 圣地亚哥` / `南美洲 圣地亚哥`。只写「圣地亚哥」会返回 `null`，不会替你猜。
